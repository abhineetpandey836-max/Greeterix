# Greeting-Card-Maker
"Greeting Card Maker with Custom Share is a responsive web application built with HTML5 and CSS3. Users choose a festival, personalise the card by editing its text, choose a font style and accent colour, add their own custom note, and share it with specific link.  The project is built using the concepts of CSE326."

## Problem statement and Solution-
India celebrates a huge number of festivals across many religions and regions, and people love sending wishes on each of them. Most of what gets forwarded is a generic image or a copied message, and it often feels impersonal. Many existing card makers also need sign ups, install an app, or place a watermark on the card.

This project tries to solve that with a lightweight website that is:

- **Instant**
- **Personal**
- **Inclusive**
- **Shareable**
- **Fast and simple**
